That's a Steal!

Game made on UT Game Jam October 2026. You are a "currency exchange" in hell. But you exchange bodies instead of currency. Bodies for souls who want to get back on Earth. For the right price, everything is possible.

  • Engine: Unity
  • Self-made: narrative design and game design
  • Itch.io: thats-a-steal

An Ordinary Space Game

Classic Space Game featuring three levels, a short story and never-before seen sound design.

Hobbit Run

My first ever video game, part of a bigger project called QuadriArcum. Developed in Godot, featuring four distinct minigames. Each minigame was programmed by a different team member to sharpen our development skills.

Inspired by the Google Chrome "Dino Run" minigame, Hobbit Run is set in the world of Lord of the Rings.

  • Engine: Godot
  • Self-made: programming, pixel art, music
  • Itch.io: quadriarcum
  • Source code: GitHub
